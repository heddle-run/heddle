# Access requests

## How to ask

Everything goes through the #it-help Slack channel with the request template.
A request that arrives as a DM will be asked to go to the channel, not because
IT is being difficult but because a DM cannot be picked up by whoever is on
duty.

## What needs an approver

| Access | Approved by |
| --- | --- |
| A SaaS tool under £50/month | Your own manager |
| A SaaS tool over that | Your manager and the finance lead |
| Production database, read-only | The service's owning team |
| Production database, write | The owning team and the CTO, and it is time-boxed to 24 hours |
| Customer PII exports | The data protection officer, always, no exceptions |

## How long it takes

Two working days for anything with one approver. Same day is possible in an
incident — say so in the request and page the on-call in #incident.

## Leavers

Access is revoked by the offboarding automation at the leaving date, not when
the last day is worked. If someone is leaving mid-week and handing over, say so
to IT or their access will vanish in the middle of the handover.
